About Layouts

Layouts control how flight information is displayed on your 64x32 LED matrix. Each layout defines the number of rows, their positions, colors, and which data fields to show.

Available Display Fields

API Data Fields

These fields are extracted from the FlightRadar24 API. You can use them in custom layouts to display different information about flights passing overhead.

About Flight Portal

Project Information

Flight Portal is a real-time flight display system for Adafruit MatrixPortal hardware with a 64x32 RGB LED matrix. It shows details of aircraft passing overhead using data from FlightRadar24.

Hardware Requirements

  • Adafruit MatrixPortal M4
  • 64x32 RGB LED Matrix Panel (P4)
  • WiFi connection
  • USB power supply

Access URLs

  • http://localhost:3100 - Direct access
  • http://flightportal:3100 - Hostname access (requires hosts file setup)

Configuration Files

All configuration files are stored in the web-interface/config/ directory:

  • device_config.json - Main device settings
  • layouts.json - Layout definitions
  • fields.json - Available API field definitions
